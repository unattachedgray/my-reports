## PART 3 — Home Lab & Hobbyist Corner (Single RTX 4090)

**EXO: Pool Your GPUs Across Devices**
The EXO framework pools heterogeneous devices (RTX 4090 + Mac + laptop + even phones) into a logical "GPU" via pipeline parallel inference. Models too large for any single device get sharded across your local network. A recent demo combined two DGX Sparks with an M3 Ultra Mac Studio for 2.8x benchmark gains. Still in alpha (v0.0.15), but functional for home clusters.
[GitHub: EXO](https://github.com/exo-explore/exo) | [Tom's Hardware: DGX + Mac Studio](https://www.tomshardware.com/software/two-nvidia-dgx-spark-systems-combined-with-m3-ultra-mac-studio-to-create-blistering-llm-system-exo-labs-demonstrates-disaggregated-ai-inference-and-achieves-a-2-8-benchmark-boost)

**QLoRA + Gradient Checkpointing: Fine-Tune 34B on a Single 4090**
The 2026 sweet spot: QLoRA with gradient checkpointing lets you fine-tune up to 34B parameters on 24GB VRAM. A 13B model that normally needs multiple A100s fits on one 4090. Stack: Unsloth + HuggingFace TRL + Axolotl. 1,000 good examples + 8 hours = production-quality adapter. 4-bit quantization now shows only 1-2% accuracy loss.
[Spheron: Fine-Tune LLMs 2026](https://www.spheron.network/blog/how-to-fine-tune-llm-2026/) | [Index.dev: LoRA vs QLoRA](https://www.index.dev/blog/top-ai-fine-tuning-tools-lora-vs-qlora-vs-full)

**Qwen 3 30B-A3B: 196 tok/s on RTX 4090**
The MoE model with ~3B active parameters remains the speed champion — faster than the 8B dense model while delivering 14B-class quality. Qwen3.5 27B also runs comfortably on 4090 with SWE-bench scores rivaling cloud models. Both are ideal for local coding agent setups.
[Home GPU LLM Leaderboard](https://awesomeagents.ai/leaderboards/home-gpu-llm-leaderboard/) | [DecodesFuture: Best GPU 2026](https://www.decodesfuture.com/articles/best-gpu-for-local-llms-2026-guide)

**VRAM Optimization Guide: The 2026 Essentials**
Key techniques stacking in 2026: GGUF Q4_K_M (92% quality, best Ollama format), FP4 quantization via TensorRT (up to 50% size reduction), PagedAttention + FlashAttention-2 (30-40% VRAM savings), and NVIDIA NVFP4/FP8 in llama.cpp (35% faster tokens). ExLlamaV2 remains the gold standard for fast quantized inference on consumer GPUs.
[Dasroot: VRAM Optimization](https://dasroot.net/posts/2026/03/optimizing-vram-usage-local-llms/) | [ExLlamaV2 Guide](https://johal.in/exllamav2-quant-gpu-fast-llama-inference-2026/)

**OpenClaw on Your Local GPU**
The viral agent framework works with local models via Ollama. Best tested local models for OpenClaw: Qwen3.5 and Llama 4 Scout with Q4 quantization on a 4090. Gives you a local autonomous agent stack without cloud API costs.
[haimaker: Best Models for OpenClaw](https://haimaker.ai/blog/best-local-models-for-openclaw/)
