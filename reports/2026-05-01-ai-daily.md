## 파트 3 — 홈랩 & 취미 코너 (단일 RTX 4090)

**실적 결과가 홈랩에 주는 시사점: 클라우드 경쟁 심화 = API 가격 하락 가능**
Google Cloud 63%, Azure 40%, AWS 28% 모두 강한 성장. OpenAI의 멀티클라우드 전환이 경쟁을 더 심화. 클라우드 API 가격이 하락할 가능성 → 로컬 홈랩과 저가 API의 혼합 사용 전략이 최적. V4-Flash $0.28/M출력은 이미 GPT-5.5($30)의 1/107.
[Fortune: AI capex](https://fortune.com/2026/04/30/big-tech-ai-earnings-cap-ex-spending/)

**DeepSeek V4-Flash Ollama 업데이트**
`ollama pull deepseek-v4-flash:q4`로 Q4_K_M 사용 가능. FP4 훈련 모델이라 Q4_K_M 품질 유지가 양호. 단일 4090(24GB) + 시스템 RAM으로 CPU 오프로딩 추론 가능. 2x 4090(48GB)에서 40-55 tok/s. 편안한 실행에는 96GB 풀 메모리 권장.
[Ollama: V4-Flash](https://ollama.com/library/deepseek-v4-flash)

**4월 오픈소스 총정리: 역대 가장 강력한 달**
한 달에 출시된 주요 오픈소스: Gemma 4(Apache 2.0), GLM-5.1(SWE-Pro 1위), MiniMax M2.7(자기 진화), Qwen3.6-35B-A3B, DeepSeek V4 Flash+Pro(MIT). RTX 4090에서 구동 가능한 프론티어급 모델이 역대 최다.
[DKLY: 4월 30일](https://www.dkly.net/blog/post/april-in-ai-30-days-that-changed-everything)

**Microsoft AI ARR $370억 = 로컬의 가치를 재확인하는 숫자**
MS의 AI 사업 ARR이 $370억(+123% YoY)이라는 것은 기업들이 AI API에 대규모 지출을 시작했다는 의미. 홈랩 사용자에게는: 동일 작업을 로컬에서 $0으로 수행할 수 있다면, 절약 효과가 그만큼 더 크다. Qwen3-Coder(73-87 tok/s) + Gemma 4 26B(85 tok/s)의 로컬 스택이 비용 효율에서 계속 경쟁력을 유지.
