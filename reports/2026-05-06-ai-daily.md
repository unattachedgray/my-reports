**Qwen 3 235B-A22B: 가장 광범위한 벤치마크 1위**
Apache 2.0 라이선스의 Qwen 3 235B-A22B가 추론·코딩·다국어에서 가장 광범위한 벤치마크 1위. RTX 4090 단일에서는 양자화 + CPU 오프로딩 필요하지만, Qwen 3 30B-A3B(196 tok/s)가 같은 패밀리의 경량 옵션.
[APXML: RTX 40 LLM](https://apxml.com/posts/best-local-llm-rtx-40-gpu)

**중국 오픈소스 4총사가 홈랩 가격 표준 재설정**
GLM-5.1(SWE-Pro 1위), MiniMax M2.7(자기 진화), Kimi K2.6, DeepSeek V4 — 모두 RTX 4090에서 다양한 양자화로 구동 가능. API 가격도 모두 서구 모델의 1/10 이하. 로컬+초저가 API의 혼합 전략이 홈랩 사용자의 표준이 됨.
[Air Street: State of AI](https://press.airstreet.com/p/state-of-ai-may-2026)

**Anthropic 금융 에이전트 10종 = 로컬 에이전트 템플릿 영감**
Anthropic이 출시한 금융 특화 사전 구성 에이전트 10종은 로컬 에이전트 구축의 좋은 템플릿. Mozilla Thunderbolt + Ollama + Gemma 4 26B(함수 호출) + V4-Flash로 자체 도메인 특화 에이전트 워크플로우 구축 가능.
