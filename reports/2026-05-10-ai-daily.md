**"AI 전도의 시대 → 평가의 시대" — Stanford HAI**

**"Jagged Capability" — 국제 AI 안전 보고서 2026**
IAISR 2026이 최근 AI 능력 변화를 "들쭉날쭉(Jagged)"으로 진단. 정량 도메인에서 큰 성능 증가(PhD 수준 과학·수학·멀티모달 추론에서 인간 기준선 초월), 하지만 주요 한계 여전. 산업이 2025년 주요 프론티어 모델의 90% 이상 생산. 평균 곡선 대신 능력 프로필을 봐야.
[Stanford AI Index 2026](https://hai.stanford.edu/ai-index/2026-ai-index-report) | [IEEE Spectrum](https://spectrum.ieee.org/state-of-ai-index-2026)

**"미국 리드 거의 사라졌다" — Stanford AI Index**

## 파트 3 — 홈랩 & 취미 코너 (단일 RTX 4090)

**Aider 2026: SWE-bench 우위 유지, 13K+ 커밋**
Aider가 2026년 오픈소스 코딩 에이전트 종합 1위 자리 유지. 멀티 파일 편집, git 통합, 모든 LLM 지원. 2023년 이후 활발히 개발, 93 릴리스 + 13,100+ 커밋(2026년 3월 기준). RTX 4090 + Qwen3-Coder-30B 조합으로 클라우드 의존 없이 코딩 워크플로우 가능.
[MindStudio](https://www.mindstudio.ai/blog/best-open-source-llms-agentic-coding-2026) | [Frontman](https://frontman.sh/blog/best-open-source-ai-coding-tools-2026/)

**Cline + Goose: VS Code/CLI 로컬 에이전트 양강**
Cline(VS Code 전용)과 Goose(Block 개발, CLI+데스크톱)가 로컬 코딩 에이전트 양강 구도. 두 도구 모두 멀티 파일 추론, 로컬 실행, 사용자 권한 단계별 승인. RTX 4090 + Ollama로 클라우드 없이 풀스택 코딩 환경 구축 가능.
[Agentic.ai](https://agentic.ai/best/open-source-coding-agents) | [DEV: Local Setup](https://dev.to/soulentheo/running-ai-coding-agents-for-free-the-open-source-local-setup-guide-2026-30h9)

**4090 양자화 가이드 — Q8_0 권장 (24GB+ VRAM)**
24GB+ VRAM에서는 Q8_0 양자화가 권장 — 품질 손실 거의 없음. 7B Q4 = 80-100 tok/s, 13B Q4 = 50-70 tok/s, 30B Q4 = 20-35 tok/s, 70B Q2 = 15-25 tok/s. 4090 스위트 스폿: 14B@Q8_0/Q5_K_M 또는 32B@Q4_K_M(KV 캐시용 ~2GB 여유).
[ToolHalla](https://toolhalla.ai/blog/best-local-llms-rtx-4090-2026) | [APXML](https://apxml.com/posts/best-local-llm-rtx-40-gpu)

**Qwen3 30B-A3B = 4090 속도왕 (196 tok/s)**
Qwen 3 30B-A3B(30B 총 파라미터, ~3B 활성 MoE) 단일 4090에서 196 tok/s 도달, 가장 빠른 30B급 모델. 24GB VRAM 여유 있게 들어가며, 코딩/추론 둘 다 강함. 클라우드 API 없이 GPT-4o급 성능 가능.
[Awesome Agents Leaderboard](https://awesomeagents.ai/leaderboards/home-gpu-llm-leaderboard/)

**Gemma 4 31B = 소비자 GPU 최강 모델**
Gemma 4 31B Dense가 소비자/프로슈머 GPU에서 가장 강력한 모델로 평가. 단일 4090에서 30-34 tok/s. Codestral(Mistral)과 DeepSeek Coder V2가 코딩 특화 최강. 로컬 GPU에서 Gemini/Claude 직접 대체 가능 수준.
[Open Source Alternatives](https://www.opensourcealternatives.to/blog/best-open-source-ai-coding-assistants)

**OpenClaw + NVIDIA NemoClaw — 항상 켜진 보안 로컬 에이전트**
NVIDIA가 OpenClaw + NemoClaw 조합으로 보안 강화된 항상-켜진 로컬 AI 에이전트 빌드 가이드 공개. 단일 4090으로 프라이버시 보장 + 클라우드 의존 없는 개인 AI 에이전트 구축 가능. 홈랩에서 24/7 운영하는 자체 호스팅 어시스턴트의 표준 청사진.
[NVIDIA Developer Blog](https://developer.nvidia.com/blog/build-a-secure-always-on-local-ai-agent-with-nvidia-nemoclaw-and-openclaw/)
