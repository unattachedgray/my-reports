## 파트 3 — 홈랩 & 취미 코너 (단일 RTX 4090)

**Qwen 3 14B — 4090 종합 추천 모델**
Qwen 3 14B가 4090에서 최고의 종합 모델로 부상. 자기보다 2배 큰 모델 능가하는 추론·수학 성능(MMLU 81.1, GSM8K 92.5). Q8_0 양자화시 9GB VRAM 여유 → 긴 컨텍스트 가능. 코딩·일반 추론 모두 GPT-4o급.
[ToolHalla](https://toolhalla.ai/blog/best-local-llms-rtx-4090-2026)

**Qwen 3 30B-A3B = 4090 속도왕 196 tok/s**
Qwen 3 30B-A3B(MoE, 활성 3B) 단일 4090에서 196 tok/s 도달, 8B Dense보다 빠르면서 14B급 품질. 24GB VRAM에 여유롭게 들어감. 로컬 코딩 워크플로우에 이상적.
[Awesome Agents 리더보드](https://awesomeagents.ai/leaderboards/home-gpu-llm-leaderboard/)

**Gemma 4 31B — 소비자 GPU 최강 모델 (코딩 강조)**
Google Gemma 4 31B가 소비자/프로슈머 GPU에서 가장 강력. 단일 파일 생성, 리팩토링, 테스트 작성에서 진정한 프로덕션 품질. RTX 4090에 정확히 들어가며, 큰 모델들이 못 들어가는 GPU 메모리 자리 점유.
[MindStudio](https://www.mindstudio.ai/blog/best-open-source-llms-agentic-coding-2026)

**Register: 로컬 AI 코딩 에이전트 자가 구축 가이드**
The Register가 5월 2일 로컬 AI 코딩 에이전트 자가 구축 가이드 공개. Aider, Cline, Open Interpreter 조합 + Ollama/llama.cpp/LM Studio + GGUF 양자화. 클라우드 API 의존 없는 풀스택 코딩 환경의 표준 청사진.
[The Register](https://www.theregister.com/2026/05/02/local_ai_coding_agents/)

**파인튜닝 민주화 — 소규모 팀도 도메인 적응 가능**
2026년 파인튜닝이 작은 팀에도 접근 가능. 연구실 없이도 도메인에 모델 적응 가능. 오픈 모델의 컨텍스트 윈도우 128K 토큰 도달 → 긴 문서 작업이 독점 API 없이도 가능. RTX 4090에서 QLoRA로 7-13B 파인튜닝 일상화.
[BentoML](https://www.bentoml.com/blog/navigating-the-world-of-open-source-large-language-models)

**llama.cpp Flash Attention + 양자화 커널 개선**
llama.cpp가 Flash Attention 지원 추가 + 양자화 커널 재작성. 새 오픈 가중치 출시(Llama 3.1, DeepSeek-R1 등)가 소비자 하드웨어 한계를 시험하면서 추론 스택도 함께 진화. 단일 4090 사용자는 무료 업그레이드.
[BentoML](https://www.bentoml.com/blog/navigating-the-world-of-open-source-large-language-models)
