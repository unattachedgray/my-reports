## 파트 3 — 홈랩 & 취미 코너 (단일 RTX 4090)

**Qwen 3.6 Plus — 1M 컨텍스트 + 폐쇄 프론티어 동급**
Qwen 3.6 Plus가 에이전틱 코딩 작업에서 가장 강력한 종합 성능. 1M 토큰 컨텍스트 윈도우(클래스 최장), 신뢰성 있는 도구 사용, 폐쇄 프론티어와 가까운 벤치마크. RTX 4090 + 양자화로 단일 GPU에서 실행 가능 → 클라우드 의존 제거.
[Agentic.ai](https://agentic.ai/best/open-source-coding-agents)

**Speculative Decoding 활용 — 1B 드래프트 + 70B 타겟**
메모리 대역폭 제약 시스템에서 throughput 증가 기법. 1B 드래프트 모델이 70B 타겟 모델을 위해 토큰 예측, 실효 tok/s 대폭 증가. RTX 4090 사용자가 70B Q2 모델을 인터랙티브 속도로 실행할 수 있게 하는 핵심 기술.
[KunalGanglani](https://www.kunalganglani.com/blog/running-local-llms-2026-hardware-setup-guide) | [DecodesFuture: Quantization](https://www.decodesfuture.com/articles/llama-cpp-gguf-quantization-guide-2026)

**BitNet b1.58 — 1.58비트 양자화의 잠재력**
BitNet b1.58은 가중치를 -1, 0, +1 세 값만 사용. Q4 양자화보다 훨씬 적은 메모리, 71.4% 적은 에너지. RTX 4090에서 더 큰 모델 실행 가능성. 아직 실험적이지만 2026년 양자화 한계 추가 돌파의 신호.
[KunalGanglani](https://www.kunalganglani.com/blog/running-local-llms-2026-hardware-setup-guide)

**Model Context Protocol (MCP) 보편화 — 에이전트 도구 표준화**
MCP가 에이전트-도구 인터페이스 표준으로 보편화. 각 프레임워크가 자체 도구 등록 포맷을 발명하지 않고, MCP가 도구 발견·스키마 검증·함수 호출 정의. 한 MCP 호환 에이전트용 도구가 다른 모든 에이전트와 작동. RTX 4090 홈랩 사용자가 도구 생태계 직접 활용 가능.
[Firecrawl: 프레임워크](https://www.firecrawl.dev/blog/best-open-source-agent-frameworks)

**llama.cpp Q4_K_M 양자화 — 140GB → 40GB**
llama-quantize 단일 명령으로 140GB FP16 모델을 Q4_K_M ~40GB로 변환. 2x RTX 4090 또는 단일 48GB Mac에서 실행 가능. 모델 다운로드 직후 양자화 → 로컬 실행의 표준 파이프라인. 7B Q4: 90-120 tok/s, 13B Q4: 50-70 tok/s, 30B Q4: 20-35 tok/s.
[DecodesFuture: Quantization](https://www.decodesfuture.com/articles/llama-cpp-gguf-quantization-guide-2026)

**TensorRT-LLM 최신 릴리스 — NVIDIA 공식 추론 스택**
NVIDIA TensorRT-LLM이 지속적 릴리스로 RTX 4090 등 컨슈머 GPU에서도 프로덕션급 추론 스택 사용 가능. PagedAttention, Continuous Batching, KV 캐시 최적화. Ollama/llama.cpp 대안으로 더 높은 throughput.
[TensorRT-LLM Releases](https://github.com/NVIDIA/TensorRT-LLM/releases)
