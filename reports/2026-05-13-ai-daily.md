## 파트 3 — 홈랩 & 취미 코너 (단일 RTX 4090)

**Qwen 3 14B + 16K ctx — 4090 코딩 일상 추천 구성**
Qwen 3 14B(Q8_0 양자화)에 16K ctx 적용한 구성이 RTX 4090 코딩 일상 추천. 9GB VRAM 여유로 긴 컨텍스트·도구 호출 가능. MMLU 81.1, GSM8K 92.5로 GPT-4o급 추론. Aider/Cline과 함께 클라우드 의존 없는 풀스택 코딩 환경.
[ToolHalla](https://toolhalla.ai/blog/best-local-llms-rtx-4090-2026) | [APXML](https://apxml.com/posts/best-local-llm-rtx-40-gpu)

**AgentFlow 7B + Flow-GRPO — 4090에서 GPT-4o 추월 가능**
ICLR 2026 AgentFlow 7B 모델이 Flow-GRPO 강화학습 정책 개선으로 GPT-4o 추월. 단일 RTX 4090에서 풀파라미터 실행 가능, QLoRA 파인튜닝도 가능. 작은 모델 + 좋은 훈련이 클라우드 의존 종식 신호.
[LLM Stats](https://llm-stats.com/ai-news) | [Lambda ICLR 2026](https://lambda.ai/blog/iclr-2026-12-papers)

**Speculative Decoding + KV 캐시 최적화 = 70B Q2 인터랙티브 속도**
Speculative Decoding(1B 드래프트 + 70B 타겟)에 KV 캐시 최적화 결합. 메모리 대역폭 제약 RTX 4090에서 70B Q2 모델을 인터랙티브 속도로 실행 가능. llama.cpp Flash Attention 업데이트로 무료 활용.
[BentoML](https://www.bentoml.com/blog/navigating-the-world-of-open-source-large-language-models)

**MCP 보편화 — 단일 4090 에이전트가 클라우드 도구 직접 활용**
Model Context Protocol(MCP)이 에이전트-도구 인터페이스 표준으로 정착. RTX 4090 로컬 에이전트가 MCP 호환 도구 생태계 직접 활용 — 검색, DB, 파일시스템, 외부 API 모두 표준 포맷으로 등록. 클라우드 모델만 가능했던 도구 사용이 로컬에서 동등.
[Firecrawl: 프레임워크](https://www.firecrawl.dev/blog/best-open-source-agent-frameworks)

**llama.cpp Q4_K_M = 140GB → 40GB, 단일 4090 + RAM 오프로딩 가능**
llama-quantize 단일 명령으로 FP16 140GB 모델 Q4_K_M ~40GB로 변환. 단일 RTX 4090(24GB) + 시스템 RAM 오프로딩으로 30-70B 클래스 모델 로컬 실행. Aider/Open WebUI 통합으로 즉시 사용 가능.
[DecodesFuture: Quantization](https://www.decodesfuture.com/articles/llama-cpp-gguf-quantization-guide-2026)

**TensorRT-LLM PagedAttention — NVIDIA 공식 프로덕션 추론 스택**
NVIDIA TensorRT-LLM이 PagedAttention, Continuous Batching, KV 캐시 최적화를 컨슈머 GPU에서 활용 가능하게 함. Ollama/llama.cpp 대비 더 높은 throughput, 프로덕션급 안정성. RTX 4090 홈랩에서 다중 사용자 LLM 서비스 운영 가능.
[TensorRT-LLM Releases](https://github.com/NVIDIA/TensorRT-LLM/releases)
