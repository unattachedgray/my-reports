## 파트 3 — 홈랩 & 취미 코너 (단일 RTX 4090)

**Qwen 3 14B + Aider — 4090 클라우드 의존 종식 구성**
Qwen 3 14B(Q8_0, 9GB VRAM) + Aider 조합이 4090 코딩 일상 추천. MMLU 81.1, GSM8K 92.5 = GPT-4o급 추론. 모든 작업이 단일 4090 + 로컬 디스크에서 완결, 클라우드 API 비용 $0. 24시간 항상-켜진 코딩 어시스턴트로 운영 가능.
[ToolHalla](https://toolhalla.ai/blog/best-local-llms-rtx-4090-2026) | [APXML](https://apxml.com/posts/best-local-llm-rtx-40-gpu)

**AgentFlow 7B Flow-GRPO — 4090에서 GPT-4o 추월**
ICLR 2026 AgentFlow 7B + Flow-GRPO 강화학습 정책 개선이 RTX 4090에서 풀파라미터 실행 가능. 검색·수학·과학 추론에서 GPT-4o 추월. QLoRA 파인튜닝도 단일 4090에서 가능. "작은 모델 + 좋은 훈련"의 표준 청사진.
[Lambda ICLR 2026](https://lambda.ai/blog/iclr-2026-12-papers)

**추론 속도 = 컨슈머 AI의 다음 전쟁터**
Fractile $2.2억 펀딩이 보낸 메시지가 홈랩에도 적용: 모델 크기·품질이 아닌 추론 지연시간이 사용자 경험 핵심. Speculative Decoding(1B 드래프트 + 70B 타겟) + KV 캐시 최적화로 4090 사용자도 70B Q2 인터랙티브 속도 도달.
[Tech Startups](https://techstartups.com/2026/05/13/top-startup-and-tech-funding-news-may-13-2025/) | [BentoML](https://www.bentoml.com/blog/navigating-the-world-of-open-source-large-language-models)

**중국 4총사 Q4 양자화 — 클라우드 의존 없는 프론티어**
GLM-5.1, M2.7, K2.6, V4 모두 Q4 양자화 GGUF가 곧 출시될 것으로 예상. Apache 2.0/MIT 라이선스 → 4090 사용자가 클라우드 의존 없이 서구 프론티어급 모델 무료 활용. 미·중 디커플링이 홈랩 사용자에게 직접 혜택.
[Air Street State of AI](https://press.airstreet.com/p/state-of-ai-may-2026)

**MCP + 로컬 에이전트 = 도구 생태계 직접 활용**
Model Context Protocol(MCP)이 에이전트-도구 인터페이스 표준화. 단일 RTX 4090 로컬 에이전트가 검색·DB·파일시스템·외부 API를 MCP 호환 도구로 직접 활용 가능. 클라우드 모델 전용이었던 도구 사용이 로컬에서 동등.
[Firecrawl](https://www.firecrawl.dev/blog/best-open-source-agent-frameworks)

**TensorRT-LLM 최신 — 4090에서 프로덕션급 추론 스택**
NVIDIA TensorRT-LLM 지속 릴리스가 RTX 4090 등 컨슈머 GPU에서 PagedAttention, Continuous Batching, KV 캐시 최적화 활용 가능. Ollama/llama.cpp 대비 더 높은 throughput. 홈랩에서 다중 사용자 LLM 서비스 운영 청사진.
[TensorRT-LLM Releases](https://github.com/NVIDIA/TensorRT-LLM/releases)
