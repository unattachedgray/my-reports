## 파트 3 — 홈랩 & 취미 코너 (단일 RTX 4090)

**Qwen 3 14B + Aider — 4090 클라우드 의존 종식**
Qwen 3 14B(Q8_0, 9GB VRAM) + Aider 조합이 4090 코딩 일상 추천 구성. MMLU 81.1, GSM8K 92.5 = GPT-4o급 추론. 모든 작업이 단일 4090 + 로컬 디스크에서 완결, 클라우드 API 비용 $0. 24/7 항상 켜진 코딩 어시스턴트로 운영 가능.
[ToolHalla](https://toolhalla.ai/blog/best-local-llms-rtx-4090-2026) | [APXML](https://apxml.com/posts/best-local-llm-rtx-40-gpu)

**AgentFlow 7B Flow-GRPO — 4090에서 GPT-4o 추월 검증**
ICLR 2026 AgentFlow 7B + Flow-GRPO 강화학습 정책 개선이 RTX 4090에서 풀파라미터 실행 가능. 검색·수학·과학 추론에서 GPT-4o 추월. QLoRA 파인튜닝도 단일 4090. "작은 모델 + 좋은 훈련"이 작은 팀에 새로운 길.
[Lambda ICLR 2026](https://lambda.ai/blog/iclr-2026-12-papers)

**중국 4총사 Q4 GGUF 임박 — 미·중 디커플링이 홈랩에 직접 혜택**
GLM-5.1, M2.7, K2.6, V4 모두 Q4 양자화 GGUF가 5-6월 출시 예상. Apache 2.0/MIT 라이선스 → 단일 4090 사용자가 클라우드 의존 없이 서구 프론티어 동급 모델 무료 활용. 가격 공격이 일반 소비자에게도 매월 전파.
[Air Street State of AI](https://press.airstreet.com/p/state-of-ai-may-2026)

**Speculative Decoding + KV 캐시 = 70B Q2 인터랙티브**
1B 드래프트 + 70B 타겟 Speculative Decoding에 KV 캐시 최적화 결합. 메모리 대역폭 제약 RTX 4090에서 70B Q2 모델 인터랙티브 속도. llama.cpp Flash Attention 업데이트로 무료 활용. 대형 모델 한계가 작년 대비 크게 완화.
[BentoML](https://www.bentoml.com/blog/navigating-the-world-of-open-source-large-language-models)

**MCP 보편화 — 로컬 에이전트가 클라우드 도구 직접 활용**
Model Context Protocol(MCP)이 에이전트-도구 인터페이스 표준으로 정착. RTX 4090 로컬 에이전트가 검색·DB·파일시스템·외부 API 모두 MCP 호환 도구로 활용. 클라우드 모델 전용이었던 도구 사용이 로컬에서 동등 가능.
[Firecrawl: 프레임워크](https://www.firecrawl.dev/blog/best-open-source-agent-frameworks)

**TensorRT-LLM 최신 — 4090 프로덕션급 추론 스택**
NVIDIA TensorRT-LLM이 PagedAttention, Continuous Batching, KV 캐시 최적화를 컨슈머 GPU에서 사용 가능. Ollama/llama.cpp 대비 높은 throughput, 프로덕션급 안정성. RTX 4090 홈랩에서 다중 사용자 LLM 서비스 운영 가능.
[TensorRT-LLM Releases](https://github.com/NVIDIA/TensorRT-LLM/releases)
