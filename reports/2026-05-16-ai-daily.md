ICLR 2026 AgentFlow 7B + Flow-GRPO 강화학습 정책 개선으로 RTX 4090에서 풀파라미터 실행. 검색·수학·과학 추론에서 GPT-4o 추월. QLoRA 파인튜닝 단일 4090 가능. "작은 모델 + 좋은 훈련"의 표준 청사진.

[TechCrunch: Meta-AI](https://techcrunch.com/2026/05/14/what-happens-when-ai-starts-building-itself/)

**Speculative Decoding + KV 캐시 = 70B Q2 인터랙티브**
1B 드래프트 + 70B 타겟 Speculative Decoding에 KV 캐시 최적화. 메모리 대역폭 제약 RTX 4090에서 70B Q2 모델 인터랙티브 속도. llama.cpp Flash Attention 업데이트로 무료. 대형 모델 한계 작년 대비 크게 완화.
[BentoML](https://www.bentoml.com/blog/navigating-the-world-of-open-source-large-language-models)

**MCP + 로컬 에이전트 = 클라우드 도구 동등 활용**
Model Context Protocol(MCP)이 에이전트-도구 표준화. 단일 4090 로컬 에이전트가 검색·DB·파일시스템·외부 API 모두 MCP 호환 도구로 활용. 클라우드 모델 전용이었던 도구 사용이 로컬에서 동등.
[Firecrawl](https://www.firecrawl.dev/blog/best-open-source-agent-frameworks)
